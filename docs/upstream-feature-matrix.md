## 迁移验收应特别保留的界限

1. 上游函数与测试文件存在只证明有实现/测试意图，不证明当前版本通过测试，更不证明用户四机可用。
2. GPU、LLM、Comfy、Tailnet、Hermes 的可用性应独立报告。设备 `aitopatom-008c` 已知驱动/固件启动故障的恢复状态尚未收到，桌面应用无法绕过它。
3. Benchmark 的 HTTP/SSH 隧道不能被泛化为所有服务已支持隧道：LlmProbe、Showcase、Comfy 都需逐条适配与验收。
4. 被动观察和主动改变必须分开。Hermes 的现有“检查”包装器尤其需要先修正副作用；本次只读研究不授权更新、关机、取消他人任务、压测或生图。
5. 第一阶段可交付完整界面与模拟数据的 Mac 闭环，后续逐项接入与验证；阶段性尚未验收的功能应明确标记，不从最终完整迁移范围中删掉。
